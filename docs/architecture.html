图纸看不出来的四条纪律

  • 封闭集合用 variant，开放集合用虚函数。 content block 和事件由 API 定死 → variant，加一种时所有 std::visit 都编译报错；Tool 和 LlmClient 用户随时会加 → 虚函数。
  • 失败是值，不是异常。 expected<LlmResponse, LlmError> 让 429 能重试， ToolResult::is_error 让读不到一个文件不会崩掉整个任务。
  • 能切掉 LLM 依赖的层就切掉。 Scheduler 只认识 runner(task, upstream)， 测试塞一个 lambda 就能验证拓扑序和环检测，不烧一分钱。
  • 生命周期契约只能写在注释里。 FakeLlm 持有 const Config&、ToolContext 全是裸指针 —— 「你必须活得比我久」这件事编译器无法表达，也无法检查。
